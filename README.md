# 花あわせ — 着物の柄から着る季節を提案するアプリ

着物・帯の写真から描かれている**文様（花・草木・吉祥文様など）を読み取り**、その柄を
**いつ着るのがふさわしいか**を 12 か月の適性として提案する Web アプリ。

「この花は何か」を当てるだけでなく、着物の「季節の先取り」——実際の盛りより半月から
一月ほど早く着て、盛りを過ぎたら着ない——という考え方にもとづいて着用時期まで示すのが
このアプリの主眼。

## 特徴

- **完全無料・API キー不要** — 画像認識はブラウザ内で完結する CLIP（transformers.js）で行う
- **写真が端末の外に出ない** — 判定はすべてローカル。サーバーに画像を送らない
- **AI が外しても使える** — 44 種の文様一覧から手で選び直せる。写真なしでも季節提案が使える
- **季節判定は AI に委ねない** — 文様の同定のみ AI が担当し、着用時期はアプリ内の
  文様マスタから計算する。毎回同じ答えが返り、根拠を自分で管理できる

## 設計

### 判定の流れ

```
写真 ──▶ CLIP（ブラウザ内・ゼロショット画像分類）──▶ 文様の候補
                                                      │
                          利用者が確認・選び直し ◀─────┘
                                                      │
                              文様マスタ（季節・意味） ─┘
                                                      │
                                                      ▼
                                   12 か月の着用適性 + 判定文
```

季節ルールを LLM に判定させず、アプリ内のデータテーブルで計算しているのは、
(1) 同じ柄に対して毎回同じ答えが返ること、(2) 出典のある知識を自分で管理できること、
(3) 誤情報を断定しないこと、を優先したため。

### 着用適性の決め方

各文様は `wearBest` / `wearGood` / `wearAvoid` の月を持つ。複数の文様が検出された場合は、
**季節を持つ文様のうち最も厳しい判定に合わせる**（ひとつでも避けたい柄があればその月は避ける）。
七宝・鶴などの通年文様は月の判定に影響させず、別枠で表示する。

季節が重ならない組み合わせ（例: 桜と菊）は「時季外れ」で片づけず、「桜楓」のように
あえて季節をまたぐ意匠が実在することを踏まえて別の説明を返す。

### ディレクトリ

| パス | 役割 |
| --- | --- |
| `src/data/motifs.ts` | 文様マスタ（44 種）。季節・意味・由来・CLIP 用プロンプト |
| `src/logic/season.ts` | 12 か月の着用適性の計算と判定文の生成 |
| `src/recognizers/` | 画像認識エンジン。`types.ts` の `Recognizer` に合わせれば差し替え可能 |
| `src/components/` | 画面部品 |

## 文様の追加

`src/data/motifs.ts` の `MOTIFS` に 1 件追記すれば、判定・図鑑・手動選択のすべてに反映される。
`prompts` には CLIP に渡す英語の説明文を 1〜2 本入れる。

## 注意

着用時期は一般的な目安であり、流派・地域・意匠によって考え方は異なる。
アプリの表示も断定を避ける文言にしてある。
